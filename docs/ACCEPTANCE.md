# Roteiro de aceite
1. Diagnóstico mostra API, banco e espaço.
2. Criar três produtos.
3. Criar projeto com três versões e confirmar estratégias distintas.
4. Criar lote 3 x 3 e confirmar nove jobs preparados.
5. Excluir/restaurar um produto.
6. Reiniciar e confirmar persistência.
7. Validar que preço não informado não aparece nos roteiros.
